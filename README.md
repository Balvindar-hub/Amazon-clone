# 🛒 Amazon Clone

A beginner-friendly **Amazon Clone website** built using **HTML and CSS**. This project is designed to help beginners understand the fundamentals of frontend web development by recreating the layout and design of an e-commerce website.

## 📌 About the Project

This project is a frontend-only recreation inspired by the design and layout of Amazon's website.

The main goal of this project is to practice:

* HTML structure and semantic elements
* CSS styling and layouts
* Flexbox
* Navigation bars
* Product cards
* Images and icons
* Responsive webpage design
* Organizing frontend project files

> **Note:** This project is created for educational and learning purposes. It is not affiliated with or endorsed by Amazon.

## ✨ Features

* 🏠 Amazon-inspired homepage
* 🔍 Search bar UI
* 🛒 Shopping cart interface
* 📦 Product sections
* 🖼️ Product images
* 📱 Responsive layout
* 🎨 Amazon-inspired styling
* 🧭 Navigation header
* 📑 Footer section

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

No frameworks or backend technologies are required.

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/amazon-clone.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! 🎉
